#### Unintended Animated Eyes Glitch

If your skin's eyes appear broken (even though you didn’t intentionally enable face animations), it’s likely due to unintended pixels on the head part of your skin. Here's an example:

![unintendedeyes](../../../assets/unintendedeyes.png)

These black lines are incorrect. Ensure that all sides of the face (head and second layer) are 8x8 pixels.

---

#### Game Crashes

If your game crashes either open an issue on [GitHub](https://github.com/Fyoncle/Elysium-Days/issues), or join our [Discord Server](https://discord.gg/WFpDr7zY8Z) and share the crash report by uploading it to [mclo.gs](https://mclo.gs/).

---

#### Errors on Screen While Joining a Server

![errors](../../../assets/errors.png)

This happens when the server is using a different version of Elysium Days than your client. Ensure you’re using the same version as the server/host.

---

#### Floating Blocks & Pink Beds in Servers

This issue occurs if you try to join a vanilla server with a modded client without installing Fabric.
Watch [this video](https://www.youtube.com/watch?v=sg91I4vg7ew) to **properly** set up a Fabric server.

---

#### Broken Fonts

![brokenfonts](../../../assets/brokenfonts.png)

Broken fonts are usually caused by insufficient allocated RAM. Elysium Days recommends 6 GB or more. If anything less is allocated, the game won’t load properly.

<Aside type="tip">
  Refer to <a href="/Elysium-Days/guides/memoryallocation">Memory Allocation</a> section to learn how to allocate more RAM.
</Aside>
